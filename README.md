# Ecobici Plan · Presentación

Presentación del Trabajo Práctico de Ciencia de Datos (UADE, 2026): **Ecobici Plan**, cuántas bicicletas dejar en cada estación según el clima previsto para el día siguiente.

**Ver la presentación:** https://nicolasmorelvulliez.github.io/ecobici-plan-presentacion/

- Avanzá con → o Espacio, `F` para pantalla completa.
- Es un único archivo `index.html`: funciona también abriéndolo con doble clic, sin conexión (salvo la demo en vivo de la aplicación).
- Material completo, aplicación y reporte: https://nicopenaloza.github.io/eco-bici-landing/

Datos: Buenos Aires Data (CC BY 2.5 AR), Open-Meteo (CC BY 4.0). Mapa, calles y edificios: © colaboradores de OpenStreetMap (ODbL). Three.js (MIT).
